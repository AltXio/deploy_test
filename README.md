# 🛒 Sistema Básico de Compras en JavaScript

Este repositorio contiene una implementación orientada a objetos en JavaScript (`compras.js`) que simula el flujo básico de compra de un usuario en una tienda online, gestionando productos, un carrito de compras y la finalización del pedido.

## 📋 Requisitos previos

* Tener instalado [Node.js](https://nodejs.org/) para ejecutar el script desde la terminal (o utilizar la consola de desarrollador de cualquier navegador web).
* Git para clonar el repositorio.
